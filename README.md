Деловой корейский · За столом переговоров (RU → KO/EN)
Единая обучающая платформа по деловым переговорам и закупкам, объединяющая три
прежних тренажёра: «Фольга» (переговоры о фольге с SAMA), «ХанДело»
(деловой корейский, уровень C1) и «Закупки» (канистры, PO, экспортная
экспертиза 전문판정).
Цель — ежедневная практика свободного устного общения на деловые темы с
русскоязычными и зарубежными (корейско/англоязычными) партнёрами. Фокус на
практическую пользу, а не на геймификацию.
290 карточек из реальных переговоров и практики, объединённых в 10 тем
Русский → корейский или русский → английский — переключается в шапке; на
карточках всегда виден английский вариант фразы («Talk in ENG»)
5 режимов + справочник, прогресс в localStorage, работает офлайн
Без внешних зависимостей: только vanilla JS + CSS + HTML

Структура проекта

project/
├── index.html   — каркас страницы: шапка, контейнер экранов, подвал
├── style.css    — все стили: тёмная/светлая тема, адаптив, стили печати

Запуск — просто двойной клик
Откройте `index.html` двойным кликом в любом браузере — всё работает.
Данные подключены обычным тегом `<script src="data.js">`, а не через fetch,
который браузеры блокируют на протоколе `file://`. Поэтому локальный сервер
не нужен: ни Python, ни Node, ни расширения.
Локальный сервер остаётся необязательным вариантом, если он удобен:
```bash
python3 -m http.server 8080   # затем http://localhost:8080
```
Прогресс (localStorage), озвучка (Web Speech API), темы и печать работают
и с `file://`, и с сервера одинаково.

Режимы
Обучение — карточки по темам: русская фраза → по клику/Space перевод,
английский вариант фразы и блок «Вариант 2» на двух языках — сверху
формальная формулировка по-корейски (koAlt, с озвучкой), под ней тот же
смысл по-английски (enAlt); далее контекст применения, примеры ответов
партнёра, отметки «изучено» и «в избранное».
Практика диалога — симуляция встречи: партнёр «произносит» фразу
(текст + озвучка), вы отвечаете готовым вариантом или своим текстом.
Это офлайн-симуляция на карточках: без сервера и без настоящей нейросети.
Тест — 10 вопросов: перевод в обе стороны, аудирование (если браузер
поддерживает озвучку), выбор фразы. Правильный ответ отмечает карточку
изученной. Дополнительно — игра «сопоставление слов» по глоссарию.
Избранное — карточки, отмеченные звездой.
Случайный режим — микс всех тем в случайном порядке.
Справочник — четыре вкладки: глоссарий с поиском, график отгрузок,
заявление на классификацию и таймлайн сроков. У таблиц свой переключатель
языка (RU/KO/EN) — он не влияет на язык карточек.
Статистика — освоение по темам, точность тестов, экспорт/импорт
прогресса, печать, сброс.
Горячие клавиши
Клавиша	Действие
`←` / `→`	предыдущая / следующая карточка
`Space`	показать перевод
`S`	озвучить фразу на корейском/английском
`F`	добавить/убрать из избранного
`L`	отметить «изучено»
`1–4`	выбрать вариант ответа в тесте
`Esc`	вернуться назад / закрыть окно
Работает и с русской раскладкой (`Ы`, `А`, `Д`).
Прогресс
Хранится в `localStorage` браузера (ключ `negot-state-v1`), тема — `negot-theme`.
«Изучено» ставится вручную или автоматически за верный ответ в тесте.
Экспорт/импорт — раздел «Статистика»: файл `progress-ГГГГ-ММ-ДД.json`.
Сброс — там же, с подтверждением.
Как добавить карточки вручную (data.js)
Все карточки лежат в `data.js`, внутри `window.APP_DATA = { ... };`, в массиве
`cards`. Скопируйте любой существующий объект карточки, поменяйте `id`
(должен быть уникальным) и тексты:
```js
{
  id: 'my-01',
  topic: 'logistics',
  source: 'my',
  ru: 'Когда планируете разместить следующий заказ?',
  ko: '다음 발주는 언제 하실 예정입니까?',
  en: 'When do you plan to place the next order?',
  context: 'Применяется при обсуждении поставок: уточнение планов клиента.',
  responses: [
    { ru: 'Думаю, в конце месяца.', ko: '다음 달 말에 할 것 같습니다.', en: 'Probably at the end of the month.' },
    { ru: 'Уточним после инвентаризации.', ko: '재고 조사 후에 확인하겠습니다.', en: 'We will decide after the stock count.' },
  ],
  level: 'middle',
  freq: 'high',
},
```
В отличие от старого `data.json`, здесь можно оставлять комментарии `//`
и не обязательно брать названия полей в кавычки. Главное — не забывайте
запятые между объектами и следить за парностью кавычек и скобок.
Если вы уже добавляли свои карточки в старый data.json
Они переносятся один в один: скопируйте свои объекты из `data.json` и вставьте
в массив `cards` файла `data.js` (JSON-записи полностью совместимы с JS —
кавычки вокруг имён полей можно не убирать). После этого `data.json` можно
удалить: платформа читает только `data.js`.
Поля:
Поле	Обязательное	Описание
`id`	да	уникальный идентификатор, латиницей
`topic`	да	один из: `greeting`, `product`, `price`, `logistics`, `contract`, `problems`, `closing`, `phrases`, `words`
`ru`	да	русская фраза (основная)
`ko`	да	корейский перевод
`en`	да	английский перевод
`context`	да	одно предложение: когда применять / ключевые слова
`responses`	да	2–3 типичных ответа партнёра для практики диалога
`level`	да	`basic` / `middle` / `advanced`
`freq`	да	`high` / `mid` / `low` — частота использования
`koAlt`	нет	второй (более формальный) корейский вариант — показывается в блоке «Вариант 2»
`enAlt`	нет	английский вариант той же формулировки — вторая строка блока «Вариант 2»
`speak`	нет	текст для озвучки, если поле `ko` содержит служебные символы (например `출하 ↔ 추락`)
`side`	нет	`ko` / `ru` / `both` — кто произносил фразу в оригинальной встрече
Чтобы добавить новую тему, допишите объект в массив `topics` и используйте
её `id` в карточках. Чтобы добавить третий язык, дополните `LANGS` в
`app.js` и добавьте в карточки поле с текстами (например `jp`).
Глоссарий (`glossary`) и таблицы справочника редактируются так же — по образцу
существующих записей:
`shipments` — график отгрузок: заголовок и колонки в трёх языках (`ru`/`ko`/`en`),
строки `rows` (номер, количество, направление, статус, комментарий) и список `notes`;
`classification` — заявление на классификацию: `colField`/`colValue` (названия
колонок), строки `rows` с полями `field` и `value` (каждое в трёх языках) и `notes`;
`timeline` — таймлайн сроков: `soon` (ближайшие шаги), `months` → `events`
(у события метка `tag`: `ship` — отгрузка, `po` — заказ, `wait` — ожидание,
`meet` — встреча) и `legend` (расшифровка меток).
После правки `data.js` просто обновите страницу (F5) — данные читаются заново.
Если после правки платформа показала «Не удалось прочитать data.js» — где-то
пропущена запятая или кавычка: место подскажет консоль браузера (F12 → Console).
Озвучка
Используется встроенный в браузер Web Speech API (офлайн, системные голоса).
Русская озвучка убрана: карточки озвучиваются на корейском и английском —
фраза, «Вариант 2» (KO и EN по отдельности) и примеры ответов (две кнопки:
по-корейски и по-английски).
Windows: Параметры → Время и язык → Речь → добавьте корейский и английский.
macOS: Системные настройки → Универсальный доступ → Произношение → Голоса.
Android/iOS: голоса ставятся вместе с языками системы.
Если голоса нет, кнопки озвучки всё равно видны, но молчат (или не показываются,
если API недоступен).
Транскрипция
Транскрипция латиницей удалена из тренажёра по запросу: в карточках, глоссарии,
тесте, диалогах и печати — только корейский текст и английский перевод.
Если поле `roman` появится в `data.js`, приложение его просто не покажет.
Озвучка
Озвучиваются только корейский и английский текст (Web Speech API, голоса
`ko-KR` и `en-US`). Русской озвучки нет — так задумано по запросу.
Печать карточек
Кнопки: «Печать темы» (в режиме обучения) и «Печать всех карточек»
(в статистике). В печать идут обе стороны карточки: русский, корейский с
романизацией и английский — удобно вырезать и носить с собой.
Как устроен код
`app.js` разбит на пронумерованные разделы с комментариями на русском:
утилиты → состояние → озвучка → роутер → экраны → печать → клавиатура.
Экраны — чистые функции, рендерящие HTML-строки в `#screen`; переходы между
экранами — через hash-роутинг (`#/learn/logistics`), поэтому работают кнопки
«назад/вперёд» браузера.
Все пользовательские строки экранируются (`esc`), внешних библиотек нет.
Проверено в Chrome и Firefox, работает на десктопе и планшете.
